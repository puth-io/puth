---
title: Puth
description: Fast, stable browser testing with a simple, client-agnostic API.
---

Puth is a browser testing tool focused on stability, performance, and rich feedback. The docs are client-agnostic: the API is the same whether you use PHP, Laravel, or another client.

**Security note:** Puth is meant for local dev and CI. Do not expose it publicly.
