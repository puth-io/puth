Puth exposes dialogs through a small set of helpers.

## Basics

- `waitForDialog()` waits for any dialog to open.
- `assertDialogOpened(message)` asserts the dialog message.
- `acceptDialog(value?)` accepts a dialog (and fills a prompt).
- `dismissDialog()` dismisses a dialog.

## Prompt input

You can type into a prompt two ways:

- `typeInDialog(value)` queues input until accept.
- `acceptDialog(value)` accepts and supplies the input in one step.
