Puth has a native Laravel package that is a drop-in replacement for Laravel Dusk. It provides a client only, so you still need a running Puth server.

## Installation

Requires Laravel 9+.

```sh
composer require --dev puth/laravel
php artisan puth:install
```

This publishes config and creates `tests/PuthTestCase.php`. Configure the Puth server URL in `config/puth.php`.

## Running tests

Add `tests/Browser` to `phpunit.xml` so `php artisan test` runs browser tests. If you already have Dusk tests in `tests/Browser`, create a new directory (e.g. `tests/Puth`) and add that instead.

```sh
php artisan test
```

## Differences to Laravel Dusk

### Changed functions

- `keys()` uses the Puppeteer keymap and is case sensitive.
- `typeInDialog(value)` is replaced by `acceptDialog(value)`.

### Unsupported functions

- `moveMouse(xOffset, yOffset)` is not supported.

### Dialogs

If you want Dusk-style dialog helpers, add the `LegacyBrowserHandling` trait when using `PuthDuskTestCase`. There is no `typeInDialog('...')`; provide the prompt text via `acceptDialog('...')`.
