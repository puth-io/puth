---
title: Browser
description: Full Browser method reference.
---

All clients expose the same Browser methods. Methods prefixed with `_` are public but mainly used internally.

## Setup and context

- `clone(site?, options?)` duplicate the Browser with a new target.
- `withinIframe(selector)` switch to the iframe at `selector`.
- `setTimeout(ms)` set base timeout.
- `setTimeoutMultiplier(factor)` scale timeouts.
- `setResolverPrefix(prefix)` set selector scope.
- `setResolverPageElements(map)` define selector aliases.

## Navigation and page

- `visit(url)` navigate to a URL.
- `setContent(html, options?)` set document HTML.
- `blank()` load `about:blank`.
- `refresh(options?)` reload page.
- `back(options?)` and `forward(options?)` history navigation.
- `evaluate(pageFunction, args?)` run JS in page.
- `quit()` close browser context.

## Window and viewport

- `maximize()` enlarge window.
- `bounds()` read window size/position.
- `setBounds(bounds)` update window size/position.
- `resize(width, height)` change viewport size.
- `move(x, y)` move window.
- `viewport()` read viewport info.

## Page data

- `url()` full URL.
- `scheme()` http/https.
- `host()`, `path()`, `port()`.
- `title()` page title.
- `content()` page HTML.

## Cookies

- `getCookieByName(name)` get a cookie.
- `setCookie(cookies)` set cookies.
- `deleteCookie(cookiesOrName)` delete cookies.

## Screenshots

- `screenshot(options?)` capture a screenshot.
- `fitContent()` resize viewport to full page.
- `enableFitOnFailure()` / `disableFitOnFailure()`.

## Clicking and mouse

- `click(selector?)` click element or current position.
- `clickLink(text, element? = 'a')` click link by `href`.
- `clickAtPoint(x, y)` click absolute coordinates.
- `clickAtXPath(expression)` click with XPath.
- `clickAndHold(selector?)` press mouse button.
- `doubleClick(selector?)`, `rightClick(selector?)`, `controlClick(selector?)`.
- `releaseMouse()` release mouse button.
- `moveMouse(xOffset, yOffset)` unsupported.
- `mouseover(selector)` hover.
- `scrollIntoView(selector)` / `scrollTo(selector)`.
- `clickablePoint(selector, offset?)` get coordinates.

## Typing and values

- `value(selector, value?)` get or set value.
- `text(selector)` get text.
- `attribute(selector, attribute)` get attribute.
- `_type(selector, value, options?)` internal typing helper.
- `type(selector, value)` clear then type.
- `typeSlowly(selector, value, pause?)` type with delay.
- `append(selector, value)` append text.
- `appendSlowly(selector, value, pause?)` append with delay.
- `clear(selector)` clear input.
- `keys(selector, keys[])` send key combos.

## Forms and buttons

- `select(selector, value?)` select option(s).
- `radio(selector, value)` select radio.
- `_check(shouldBeChecked, selector, value?)` internal check helper.
- `check(selector, value?)` / `uncheck(selector, value?)`.
- `press(textOrName)` click a button by label/name.
- `pressAndWaitFor(textOrName)` click and wait for enabled.

## Drag helpers

- `drag(from, to)` drag element to target.
- `dragOffset(selector, x, y)` drag by offset.
- `dragUp/dragDown/dragLeft/dragRight(selector, offset)`.

## Waiting

- `_waitFor(selector, options?)` internal wait helper.
- `waitFor(selector, timeout?)` wait for visible.
- `waitUntilMissing(selector, timeout?)` wait for hidden.
- `waitForLink(text, timeout?)` wait for link.
- `waitForInput(name, timeout?)` wait for input by name.
- `waitForLocation(url, timeout?)` wait for URL.
- `waitForEvent(type, target?, timeout?)` wait for DOM event.
- `waitForNotPresent(selector, options?)` wait for removal.
- `waitForText(text, timeout?, ignoreCase?)` wait for text.
- `waitUntilMissingText(text, timeout?, ignoreCase?)` wait for text to disappear.
- `waitForTextIn(selector, text, timeout?, ignoreCase?)` wait for text in selector.
- `waitUntilMissingTextIn(selector, text, timeout?, ignoreCase?)`.
- `waitUntil(pageFunction, args?, message?, options?)` custom wait.
- `waitUntilAttribute(selector, attribute, value, message, options?)`.
- `waitUntilEnabled(selector, options?)`.
- `waitUntilDisabled(selector, options?)`.

## Finding elements

- `find(selector, options?)` first match or null.
- `findAll(selector, options?)` all matches.
- `findOrFail(selector, options?)` all matches or throw.
- `firstOrFail(selector, options?)` first match or throw.
