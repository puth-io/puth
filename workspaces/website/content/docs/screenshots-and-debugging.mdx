## Screenshots

- `screenshot(options?)` returns image bytes.
- `fitContent()` resizes the viewport to the full page size.

`screenshot` is not supported on iframes.

## Fit on failure

Puth can auto-fit the window before error snapshots:

- `enableFitOnFailure()`
- `disableFitOnFailure()`
