## Getting Puth stable (current)

Fix bugs and remove obstacles that hinder everyday use.

## Releasing a paid Pro version

A paid version is planned to fund full-time development and add advanced features. The free version stays free and is always enough to view snapshots. The current plan is a one-year license that grants indefinite access to the last version released during the active license period.
