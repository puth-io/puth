## Creating and reusing browsers

A Browser instance wraps a page or a frame. Most clients create one per test, but you can reuse it:

- `clone(site?, options?)` duplicates the browser with a new page or frame while keeping timeouts and resolver config.
- `withinIframe(selector)` scopes the Browser to the iframe found at `selector`.

## Navigation

Use these for page navigation and reloads:

- `visit(url)` loads a URL.
- `refresh(options?)` reloads the page.
- `back(options?)` and `forward(options?)` navigate history.
- `blank()` visits `about:blank`.
- `setContent(html, options?)` replaces the document HTML.

## Window and viewport

These are page-only (not frames):

- `maximize()` expands the window.
- `bounds()` reads window size/position.
- `setBounds(bounds)` updates window size/position.
- `resize(width, height)` sets viewport size.
- `move(x, y)` moves the window.
- `viewport()` returns current viewport info.

## URLs and page data

Quick accessors for URL parts and page state:

- `url()` full URL string.
- `scheme()` http/https.
- `host()`, `path()`, `port()`.
- `title()` document title.
- `content()` page HTML.
