## Cookies

- `getCookieByName(name)` returns a cookie object or null.
- `setCookie(cookies)` sets one or more cookies.
- `deleteCookie(cookiesOrName)` deletes by name or list.

Cookie helpers only work on pages (not iframes).

## URL parts

These return the current page parts:

- `url()` full URL string.
- `scheme()` http/https.
- `host()` domain.
- `path()` path part.
- `port()` port or default.
