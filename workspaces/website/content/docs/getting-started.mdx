---

## 1) Run the Puth server

Run Puth locally using Docker or npm.

Docker:
`docker run -it --rm -p 127.0.0.1:7345:7345 puthio/puth:0.7.1`

npm:
`npm install --global puth` then `puth start`

## 2) Point your client at Puth

Configure your client to use the Puth server URL, usually:

`http://127.0.0.1:7345`

## 4) Run tests in CI

Start the Puth server in your CI job and run your client tests as usual. Keep Puth on a private network only.
