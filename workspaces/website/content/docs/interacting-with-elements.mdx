## Clicking

- `click(selector?)` clicks the element or the current mouse position.
- `clickLink(text, element? = 'a')` clicks a link by `href` value.
- `clickAtPoint(x, y)` clicks absolute coordinates.
- `clickAtXPath(expression)` clicks using XPath.
- `clickAndHold(selector?)`, `doubleClick(selector?)`, `rightClick(selector?)`, `controlClick(selector?)`.
- `releaseMouse()` releases the mouse button.

## Typing and values

Use these for inputs and content:

- `type(selector, value)` clears and types.
- `typeSlowly(selector, value, pause?)` types with delay.
- `append(selector, value)` types without clearing.
- `appendSlowly(selector, value, pause?)` appends with delay.
- `clear(selector)` clears an input.
- `keys(selector, keys[])` sends key combos.
- `value(selector, value?)` gets or sets the value.
- `text(selector)` returns `innerText`.
- `attribute(selector, attribute)` reads an attribute.

## Forms

- `select(selector, value?)` selects one or more options.
- `radio(selector, value)` selects a radio input.
- `check(selector, value?)` / `uncheck(selector, value?)` toggles checkboxes.

## Buttons

- `press(textOrName)` clicks a button by label or name.
- `pressAndWaitFor(textOrName)` clicks and waits for it to be enabled.

## Mouse and drag

- `mouseover(selector)` hovers an element.
- `scrollIntoView(selector)` / `scrollTo(selector)`.
- `clickablePoint(selector, offset?)` returns coordinates.
- `drag(from, to)` drags one element onto another.
- `dragOffset(selector, x, y)` drags by offset.
- `dragUp/dragDown/dragLeft/dragRight(selector, offset)` convenience methods.
